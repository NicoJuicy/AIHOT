# Reporting security issues

If you find a permission bypass, a leaked secret, an injection, or any other issue that could affect the security of a deployment, contact the maintainers through [GitHub private vulnerability reporting](https://github.com/KKKKhazix/AIHOT/security/advisories/new).

Please include:

- the affected commit, how it is deployed, and any environment details needed;
- the minimal steps to reproduce the issue in an environment you are allowed to test;
- the possible impact, plus logs or screenshots with sensitive information removed.

Do not disclose exploitable details in public issues, discussions or PRs before a fix, and do not upload real keys, passwords, cookies, user data or full databases. For ordinary usage questions and non-security bugs, use [Discussions](https://github.com/KKKKhazix/AIHOT/discussions/categories/q-a) or [Issues](https://github.com/KKKKhazix/AIHOT/issues/new/choose).

Security issues are verified and fixed on the latest `main` of the public repository first; there are no separately maintained long-term support branches. The maintainers will confirm the scope, prepare a fix and publish a notice when appropriate. There is no fixed response time yet.
